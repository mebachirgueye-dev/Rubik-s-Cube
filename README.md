# Rubik’s Cube 3D

Cube Rubik 3×3 interactif en HTML, CSS et JavaScript. Tu peux le faire tourner, mélanger les faces, annuler un coup et reprendre ta partie plus tard : la position du cube est enregistrée automatiquement dans le navigateur.

## Fonctionnalités

- Manipulation 3D à la souris ou au doigt
- Rotation d’une couche en glissant une pastille
- Rotation du cube entier en glissant le fond
- Mélange, annulation et réinitialisation
- Sauvegarde automatique de la position, de l’angle de vue et de l’historique des coups
- Fenêtre de confirmation avant de réinitialiser le cube

## Utilisation

Ouvre `index.html` dans un navigateur.

| Action | Comment faire |
| --- | --- |
| Tourner une face | Glisse une pastille colorée |
| Faire pivoter le cube | Glisse le fond blanc |
| Mélanger | Bouton **Mélanger** ou barre d’espace |
| Annuler | Bouton **Annuler** |
| Réinitialiser | Bouton **Réinitialiser**, puis confirme dans la popup |

Raccourcis clavier : `U` `D` `L` `R` `F` `B` (Shift = mouvement inverse).

## Fichiers

- `index.html` — page principale
- `style.css` — mise en page et rendu 3D
- `cube.js` — logique du cube, sauvegarde et popup
